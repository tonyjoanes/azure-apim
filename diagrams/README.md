# APIM Diagrams

This directory contains Mermaid diagrams to help visualize Azure API Management concepts and workflows.

## Available Diagrams

1. **[Architecture](architecture.mmd)** - Overall APIM architecture and components
2. **[Request Flow](request-flow.mmd)** - How requests flow through APIM
3. **[Policy Execution](policy-execution.mmd)** - Order of policy execution
4. **[Authentication Flows](auth-flows.mmd)** - Different authentication methods
5. **[Products & Subscriptions](products-subscriptions.mmd)** - Product and subscription model

## Viewing Diagrams

You can view these diagrams by:

1. Using a Mermaid preview extension in VS Code
2. Copying the content to [Mermaid Live Editor](https://mermaid.live)
3. Viewing on GitHub (which renders Mermaid automatically)

## Mermaid Syntax

All diagrams use Mermaid syntax, a simple markdown-like script language for generating diagrams from text.

Learn more: [Mermaid Documentation](https://mermaid.js.org/)
